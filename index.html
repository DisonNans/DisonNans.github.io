DisonNans Creator CRM

DisonNans Creator CRM is a personal, locally hosted creator dashboard for managing stream analytics, highlights and channel performance.

YouTube Analytics integration

The application uses Google OAuth 2.0 to request read-only access to the owner's YouTube Analytics reports. This data is used only to display analytics inside the local CRM dashboard.

Data handling

OAuth tokens and downloaded analytics are stored locally on the owner's computer. The application does not sell Google user data or share it with advertisers or unrelated third parties.
