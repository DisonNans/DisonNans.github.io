Privacy Policy — DisonNans Creator CRM

Last updated: September 28, 2026

DisonNans Creator CRM is a personal, locally hosted application used by its owner to review creator and streaming analytics.

Google user data

The application requests read-only access to YouTube Analytics through Google OAuth 2.0. It uses this access only to retrieve analytics for the Google/YouTube account that explicitly authorizes the application.

Storage

OAuth tokens and downloaded analytics are stored locally on the owner's computer. The application does not operate a remote user database for Google account data.

Sharing and sale of data

Google user data is not sold, rented, shared with advertisers, or transferred to unrelated third parties by DisonNans Creator CRM.

Retention and deletion

Local OAuth tokens and analytics files remain on the owner's computer until the owner deletes them. OAuth access can be revoked at any time from the Google Account security settings.

Security and scope

The application uses Google's OAuth 2.0 flow and requests only the YouTube Analytics read-only scope required for its analytics features.

Contact

Contact the project owner through the DisonNans GitHub profile.
